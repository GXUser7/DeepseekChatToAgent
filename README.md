# Orbit · DeepSeek workspace

Лёгкий локальный веб-интерфейс для DeepSeek в стиле **Material 3 Expressive**. Мягкие цветные поверхности, светлая и тёмная темы, потоковые сообщения и инструменты — без npm, сборки фронтенда и API-ключа. Используется ваша сессия chat.deepseek.com.

## Возможности

- **Потоковый чат:** Markdown, таблицы, код и копирование ответа.
- **Ход размышлений:** отдельные сворачиваемые блоки с потоком THINK, который возвращает сам DeepSeek. Интерфейс не придумывает этапы или рассуждения.
- **Ход работы:** получение PoW, ожидание модели, размышления, поиск, выполнение команд и длительность запроса.
- **Терминал под контролем:** карточка команды, рабочая папка, явное разрешение или отказ, потоковый вывод и код завершения. Ни одна команда не запускается автоматически. Модель может пояснить шаг перед блоком `<terminal>`; если блоков несколько, выполняется только первый, и DeepSeek получает об этом сообщение.
- **Новый чат на сайте:** по умолчанию каждый диалог Orbit создаёт отдельный чат на chat.deepseek.com (кнопка в шапке открывает его). В настройках можно вернуть один общий чат из `config.json`.
- **Контекст:** у каждого ответа можно раскрыть текст, который реально ушёл в DeepSeek (стартовый промпт, ОС, папка, результат команды), а в шапке виден размер контекста чата в токенах.
- **История диалогов:** сохраняется в этом браузере, есть удаление и экспорт JSON.
- **Настройки:** стартовый промпт, раскрытие размышлений по умолчанию, авторизация.
- **Экспертный режим и поиск:** переключатели у поля ввода; видно, что именно искал DeepSeek, найденные источники и ссылки-сноски `[citation:N]` в ответе.
- **Рабочая папка:** кнопка с папкой внизу боковой панели, системный выбор через «Обзор…» или ввод пути вручную.
- **Адаптивный интерфейс:** на узких экранах история открывается отдельной панелью.
- **Локальные ресурсы:** шрифты, Markdown-парсер и HTML-санитайзер включены в проект; CDN не нужен.

## Запуск

Требуются **Python 3.10+**, **Node.js** для PoW и Chrome для первоначальной авторизации. Для работы с DeepSeek нужен интернет: локален интерфейс и сервер, а не сама модель.

```powershell
pip install -r requirements.txt
python web_server.py
```

Если используете уже созданное виртуальное окружение:

```powershell
.\.venv\Scripts\python.exe web_server.py
```

Откройте **http://127.0.0.1:8765**.

Можно запустить двойным щелчком по `start_web.bat`. Окно сервера нужно оставить открытым; для завершения нажмите `Ctrl+C`.

Другой порт:

```powershell
python web_server.py --port 8080
```

### Авторизация

Если `config.json` уже содержит рабочую сессию, можно сразу писать. Надпись «готов» означает наличие конфигурации; её действительность проверяется при запросе.

Если нужен вход:

1. Откройте **Настройки → Обновить авторизацию**.
2. В открывшемся Chrome войдите на сайт DeepSeek.
3. Отправьте там хотя бы одно сообщение, чтобы существующий `auth_fetcher.py` перехватил сессию.
4. Вернитесь в Orbit и отправьте запрос.

Браузер авторизации не открывается сам при ошибке чата. Cookies и токены не передаются веб-интерфейсу.

### Работа с чатом

- `Enter` — отправить, `Shift+Enter` — новая строка.
- `Ctrl+N` / `⌘N` — новый диалог, когда сочетание не перехватывается браузером.
- Кнопка отправки во время ответа превращается в **остановку**.
- Рабочая папка выбирается кнопкой внизу боковой панели → **Обзор…** или вводом пути. Смена папки блокируется на время выполнения запроса.
- Команду терминала сначала проверьте, затем разрешите или отклоните. Разрешение действует только на одну команду.
- Стартовый промпт меняется в настройках и применяется к новым диалогам. ОС, оболочка и текущая папка добавляются автоматически.

### История и конфиденциальность

Диалоги и настройки сохраняются в `localStorage` текущего браузера. Экспорт содержит тексты сообщений, размышления и вывод команд — не публикуйте его, если в них есть личные данные. При перезапуске сервера предыдущие сообщения передаются как ограниченный текстовый контекст для продолжения диалога; удалённые идентификаторы сообщений не сохраняются на диск.

Запросы и содержимое команд отправляются в DeepSeek. Это не офлайн-модель. Очистка локальной истории **не удаляет** сообщения на стороне DeepSeek.

`config.json`, профиль Chrome, логи и виртуальное окружение исключены из Git. Не публикуйте эти файлы. Сырые потоки ответов больше не пишутся в `stream_debug.log`; старый файл автоматически не удаляется.

### Ограничения и безопасность

- Сервер слушает **только `127.0.0.1`**, проверяет Host и Origin. Не публикуйте его в интернете и не открывайте доступ через прокси без отдельной защиты.
- Команды выполняются с правами пользователя сервера, это **не песочница**. Даже разрешённую команду необходимо внимательно прочитать.
- Одновременно выполняется один запрос; за один ход разрешено не более 12 команд.
- В веб-режиме команда ограничена 120 секундами и примерно 1 МиБ вывода. Кнопка остановки отменяет ожидание разрешения и пытается завершить текущий процесс; независимо запущенные дочерние процессы могут остаться работать.
- История ограниченно восстанавливает контекст, но не является точной копией серверного состояния DeepSeek. Очень длинные старые сообщения обрезаются.
- Интеграция использует веб-протокол DeepSeek, который может измениться. При проблемах проверьте авторизацию, Node.js и доступность сервиса.

## Консольный режим

Сохранён запуск без веб-интерфейса:

```powershell
python deepseek_client.py
python deepseek_client.py "напиши hello world на Python"
```

Префиксы `/s` или `/search` включают поиск, `/e` или `/expert` — экспертный режим. Команды в CLI также требуют разрешения.

## Структура

```text
web_server.py          Локальный HTTP-сервер, NDJSON, разрешения и отмена
web/                  HTML, CSS, JavaScript и локальные ресурсы
  vendor/             Marked, DOMPurify, Onest и Manrope с лицензиями
deepseek_client.py    Протокол DeepSeek, потоковый парсер, PoW и терминал
auth_fetcher.py       Существующая авторизация через Chrome
pow_solver.js         PoW-решатель на Node.js
sha3_wasm_bg.wasm      WASM для PoW
tests/                Локальные тесты без реальных API-запросов
start_web.bat         Запуск на Windows
```
