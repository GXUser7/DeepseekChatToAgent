# DeepseekChatToAgent · Orbit

**Локальный веб-интерфейс к DeepSeek, который умеет выполнять команды в вашем терминале — только с вашего явного разрешения.**

Orbit — лёгкий workspace в стиле Material 3 Expressive: потоковый чат, ход размышлений, поиск, история диалогов и терминал под контролем. Работает на вашей сессии chat.deepseek.com — **API-ключ не нужен**. Без npm, без сборки фронтенда и без CDN.

## Зачем это

Обычный чат с моделью не видит ваш проект. Orbit передаёт в DeepSeek контекст: ОС, оболочку и текущую рабочую папку, а ответы модели может превращать в команды терминала. Каждая команда сначала показывается карточкой, и только вы решаете — выполнить её или отклонить.

## Возможности

- **Потоковый чат** — Markdown, таблицы, блоки кода, копирование ответа.
- **Ход размышлений** — отдельные сворачиваемые блоки с потоком THINK, который возвращает сам DeepSeek. Интерфейс не придумывает этапы рассуждений.
- **Ход работы** — видно получение PoW, ожидание модели, размышления, поиск, выполнение команд и длительность запроса.
- **Терминал под контролем** — карточка команды, рабочая папка, явное разрешение или отказ, потоковый вывод и код завершения. Модель может пояснить шаг перед блоком `&lt;terminal&gt;`. Если блоков несколько, выполняется только первый, и DeepSeek получает об этом сообщение. Команда, оформленная обычным блоком кода в конце ответа, тоже попадает в карточку.
- **Автоапрув** — переключатель в настройках (или кнопка «Всегда» на карточке) запускает команды без подтверждения. По умолчанию выключен.
- **Гибкий вывод команд** — одна строка по умолчанию; в настройках можно выбрать «5 строк» или «Полностью».
- **Отдельный чат на сайте** — каждый диалог Orbit создаёт собственный чат на chat.deepseek.com. Если создать чат не удалось, запрос завершается ошибкой, чтобы не переписать общий чат из `config.json`.
- **Прозрачный контекст** — у каждого ответа можно раскрыть текст, который реально ушёл в DeepSeek; в шапке виден размер контекста в токенах.
- **История диалогов** — в `localStorage` браузера, с удалением и экспортом в JSON.
- **Размышления и поиск** — переключатели у поля ввода (DeepThink включён по умолчанию), найденные источники и ссылки-сноски `[citation:N]`.
- **Рабочая папка** — кнопка в боковой панели, системный выбор «Обзор…» или ручной ввод пути.
- **Адаптивный интерфейс** — на узких экранах история открывается отдельной панелью.
- **Локальные ресурсы** — шрифты, Markdown-парсер и HTML-санитайзер лежат в репозитории.

## Быстрый старт

Нужны **Python 3.10+**, **Node.js** (для PoW) и **Chrome** (для первой авторизации). Для работы с DeepSeek нужен интернет: локален интерфейс и сервер, а не сама модель.

```powershell
pip install -r requirements.txt
python web_server.py
```

Или через готовое виртуальное окружение:

```powershell
.\.venv\Scripts\python.exe web_server.py
```

Откройте **http://127.0.0.1:8765**. На Windows можно запустить двойным щелчком по `start_web.bat`; окно сервера оставьте открытым, для завершения нажмите `Ctrl+C`.

Другой порт:

```powershell
python web_server.py --port 8080
```

## Авторизация

Если `config.json` уже содержит рабочую сессию, можно сразу писать. Надпись «готов» означает наличие конфигурации; её действительность проверяется при запросе.

Если нужен вход:

1. Откройте **Настройки → Обновить авторизацию**.
2. В открывшемся Chrome войдите на сайт DeepSeek.
3. Отправьте там хотя бы одно сообщение — `auth_fetcher.py` перехватит сессию.
4. Вернитесь в Orbit и отправьте запрос.

Браузер авторизации не открывается сам при ошибке чата. Cookies и токены не передаются веб-интерфейсу.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Enter` | Отправить сообщение |
| `Shift+Enter` | Новая строка |
| `Ctrl+N` / `⌘N` | Новый диалог |

Во время ответа кнопка отправки превращается в **остановку**. Смена рабочей папки блокируется на время выполнения запроса, а разрешение на команду действует только для одной команды. Стартовый промпт задаётся в настройках и применяется к новым диалогам; ОС, оболочка и текущая папка добавляются автоматически.

## Консольный режим

Веб-интерфейс не обязателен:

```powershell
python deepseek_client.py
python deepseek_client.py "напиши hello world на Python"
```

Префиксы `/s` или `/search` включают поиск, `/e` или `/expert` — экспертный режим. Команды в CLI также требуют разрешения.
## Безопасность

- Сервер слушает **только `127.0.0.1`** и проверяет заголовки `Host` и `Origin`. Не публикуйте его в интернете и не открывайте доступ через прокси без отдельной защиты.
- Команды выполняются с правами пользователя сервера — это **не песочница**. Даже разрешённую команду внимательно прочитайте.
- Одновременно выполняется один запрос; за один ход разрешено не более 12 команд.
- В веб-режиме команда ограничена 120 секундами и примерно 1 МиБ вывода. Остановка отменяет ожидание разрешения и пытается завершить процесс; независимо запущенные дочерние процессы могут остаться работать.
- Запросы и содержимое команд отправляются в DeepSeek. Это **не офлайн-модель**.
- `config.json`, профиль Chrome, логи и виртуальное окружение исключены из Git — не публикуйте их.

## Конфиденциальность

Диалоги и настройки хранятся в `localStorage` текущего браузера. Экспорт содержит тексты сообщений, размышления и вывод команд — не публикуйте его, если там есть личные данные. При перезапуске сервера предыдущие сообщения передаются как ограниченный текстовый контекст; удалённые идентификаторы сообщений не сохраняются на диск. Очистка локальной истории **не удаляет** сообщения на стороне DeepSeek.

## Структура проекта

```text
web_server.py          Локальный HTTP-сервер: NDJSON, разрешения и отмена
web/                   HTML, CSS, JavaScript и локальные ресурсы
  vendor/              Marked, DOMPurify, шрифты Onest и Manrope с лицензиями
deepseek_client.py     Протокол DeepSeek, потоковый парсер, PoW и терминал
auth_fetcher.py        Авторизация через Chrome
pow_solver.js          PoW-решатель на Node.js
sha3_wasm_bg.wasm      WASM для PoW
tests/                 Локальные тесты без реальных API-запросов
start_web.bat          Запуск на Windows
```

## Ограничения

- Интеграция использует веб-протокол DeepSeek, который может измениться. При проблемах проверьте авторизацию, Node.js и доступность сервиса.
- История ограниченно восстанавливает контекст и не является точной копией серверного состояния DeepSeek; очень длинные старые сообщения обрезаются.
