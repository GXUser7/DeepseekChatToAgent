# 🌟 Консольный клиент DeepSeek (Portable)

Это автономная, портативная сборка клиента DeepSeek для Windows. Она предоставляет мощный терминальный интерфейс для общения с ИИ и автоматической синхронизации токенов и файлов cookie (через Chromium). Все работает прямо в консоли!

---

## ✨ Основные возможности

1. **Интерактивный консольный ИИ-агент**
   - Прямая интеграция с терминалом для интерактивного общения и автоматического выполнения команд.
   - Потоковый вывод ответов и рассуждений (thinking) в реальном времени.
   - Динамические параметры запросов, встроенное автоматическое прохождение защиты (PoW) и отображение поисковых запросов/результатов.

2. **Чистая консоль (Carriage Return `\r`)**
   - Интерактивные команды обновляются в одной активной строке терминала.
   - Никакого мусора в логах. Ваш терминал остается идеально чистым.
   
3. **Портативность и автономность**
   - Файлы конфигурации, профили Chrome и логи сохраняются прямо рядом со скриптом.
   - Работает «из коробки» прямо в папке вашего проекта!

---

## 📁 Файлы релиза

- **deepseek_client.py** — Главный скрипт консольного клиента.
- **auth_fetcher.py** — Скрипт для получения авторизации (поддерживает Windows и macOS).
- **pow_solver.js** и **sha3_wasm_bg.wasm** — Быстрый решатель Proof-of-Work на Node.js.
- **requirements.txt** — Список зависимостей Python.

## 🚀 Как запускать и использовать

### 1. Первоначальный запуск и авторизация

При первом запуске скрипта (или когда истекает сессия) автоматически откроется браузер с сайтом DeepSeek. **Чтобы скрипт смог успешно перехватить авторизацию и привязаться к сессии, вам необходимо:**

1. Авторизоваться на сайте (если вы еще не вошли).
2. Выбрать нужную модель и настройки в интерфейсе.
3. **Обязательно написать и отправить хотя бы одно любое сообщение** в чат прямо в браузере.

Как только вы отправите сообщение, скрипт автоматически перехватит нужные токены и ID чата. После этого браузер можно будет свернуть или закрыть, и продолжить общение уже в терминале.

### 2. Запуск интерактивного режима

Для запуска классического интерактивного чата в терминале выполните команду:
```cmd
python deepseek_client.py
```

### 3. Быстрый запрос (Single-shot)

Вы можете отправить запрос ИИ напрямую из терминала (удобно для скриптов и автоматизации):
```cmd
python deepseek_client.py "напиши hello world на node.js"
```

### 4. Встроенные команды в чате

В интерактивном режиме или при отправке разового запроса вы можете использовать специальные команды в начале сообщения для активации скрытых функций:
- `/s` или `/search` — включает **поиск в интернете** для данного запроса.
  *Пример:* `/s какая сейчас погода в Москве?`

### 5. Автоматическое выполнение команд терминала

Скрипт глубоко интегрирован с вашей командной строкой. Если вам нужно что-то сделать в терминале (установить пакет, запустить сборку, создать файл или папку, найти что-то в системе), вам **не нужно делать это вручную**.
Просто напишите об этом в чат! ИИ сам сформирует нужную команду, выполнит её в фоне и проанализирует вывод (результат).
*Пример:* `создай папку test и положи туда файл index.js с console.log`

> **⚠️ Важное правило:** Обязательно в первом запросе к ИИ указывайте, в какой операционной системе вы работаете (например, *"Я нахожусь в Windows PowerShell"*). Это поможет избежать ошибок при генерации терминальных команд!
