# DeepseekChatToAgent · Orbit

Локальный веб-интерфейс к DeepSeek, который выполняет команды в вашем терминале — только с вашего разрешения — и показывает Git так, что разберётся и новичок.

Работает на вашей сессии chat.deepseek.com, API-ключ не нужен. Без npm, сборки и CDN.

## Возможности

**Чат**
- Потоковые ответы с Markdown, таблицами и кодом; размышления DeepThink и поиск в интернете с источниками.
- Карточка команды: команда, папка, «Выполнить», «Выполнять всегда», «Отклонить», вывод и код завершения. Вывод — одной строкой, последние 5 строк или целиком.
- Текстовые файлы можно прикрепить скрепкой, перетащить или вставить из буфера (до 5 файлов по 200 КБ).
- У каждого ответа можно посмотреть, какой текст ушёл в DeepSeek; в шапке — размер контекста и ссылка на чат на сайте.
- Ошибку можно повторить одной кнопкой. Каждый диалог — отдельный чат на сайте DeepSeek.

**Диалоги** — поиск по тексту, закрепление, переименование (или двойной щелчок по заголовку), удаление, экспорт и импорт JSON.

**Git** — схема из трёх мест: *папка проекта → история на компьютере → сервер*. Кнопки «Коммит», «Отменить коммит», «Push» и «Pull» стоят на стрелках между ними. При наведении схема подсвечивает, что куда переместится и сколько, а строка под ней объясняет результат. Рекомендуемый следующий шаг выделен.
- Изменённые файлы с галочками, diff с номерами строк, отмена правок в файле, «Не отслеживать» (строка в `.gitignore`). Служебные файлы вроде `__pycache__` по умолчанию не отмечены.
- Коммит только выбранных файлов; название и описание может написать DeepSeek по diff.
- История коммитов с отметкой «на сервере / только здесь», просмотр любого коммита, отмена последнего неотправленного коммита и безопасный откат (revert) любого.
- Отложить и вернуть изменения (stash), ветки: создать, перейти, слить, удалить.
- «Включить Git» в папке без репозитория и подключение сервера по адресу GitHub/GitLab.
- Pull с конфликтом не оставляет репозиторий сломанным: Orbit отменяет слияние, показывает ответ Git и предлагает разобрать конфликт с DeepSeek. Push никогда не бывает принудительным.

**Настройки** — вход в DeepSeek, стартовый промпт, автоподтверждение команд, вид вывода, тема (светлая, тёмная, как в системе), данные.

## Быстрый старт

Нужны **Python 3.10+**, **Node.js** (для PoW), **Chrome** (для первого входа) и **Git** (для раздела Git).

```powershell
pip install -r requirements.txt
python web_server.py
```

Откройте **http://127.0.0.1:8765**. На Windows можно запустить `start_web.bat`. Другой порт: `python web_server.py --port 8080`.

## Вход в DeepSeek

Если `config.json` уже содержит рабочую сессию, можно сразу писать. Иначе: **Настройки → Войти**, в открывшемся Chrome войдите на сайт DeepSeek и отправьте там одно сообщение — `auth_fetcher.py` сохранит сессию. Cookies и токены не передаются в браузерную часть Orbit.

## Клавиши

| Клавиши | Действие |
| --- | --- |
| `Enter` / `Shift+Enter` | Отправить / новая строка |
| `Ctrl+N` / `⌘N` | Новый диалог, если браузер разрешает перехват |
| `/` | Поиск в разделе «Диалоги» |
| `Esc` | Закрыть меню |

## Консольный режим

```powershell
python deepseek_client.py "напиши hello world на Python"
```

Префиксы `/s` — поиск, `/e` — экспертный режим. Команды тоже требуют разрешения.

## Безопасность

- Сервер слушает только `127.0.0.1` и проверяет `Host` и `Origin`. Не открывайте его в сеть.
- Команды выполняются с правами вашего пользователя — это не песочница. Читайте команду перед запуском. Лимиты: 120 секунд и около 1 МиБ вывода; после 25 команд подряд Orbit спрашивает даже с автоподтверждением.
- Git вызывается с фиксированными аргументами, без оболочки. Браузер может работать только с файлами, которые показывает `git status`. Пока DeepSeek отвечает, изменяющие Git-операции заблокированы.
- Для подготовки сообщения коммита в DeepSeek уходит diff выбранных файлов. Не отмечайте файлы с секретами.
- `config.json`, профиль Chrome, логи и виртуальное окружение исключены из Git.

## Данные

Диалоги, настройки и черновики коммитов хранятся в `localStorage` браузера. Экспорт содержит тексты сообщений и вывод команд. Удаление в Orbit не трогает чаты на сайте DeepSeek.

## Структура

```text
web_server.py       HTTP-сервер: чат (NDJSON), разрешения, отмена, папка, Git API
git_tools.py        Git-операции и подготовка сообщения коммита
deepseek_client.py  Протокол DeepSeek, потоковый парсер, PoW и терминал
auth_fetcher.py     Вход через Chrome
pow_solver.js       PoW на Node.js (+ sha3_wasm_bg.wasm)
web/                Интерфейс: index.html, styles.css, app.js, git.js, theme.js
  vendor/           Marked, DOMPurify, шрифт Onest с лицензиями
tests/              Тесты без реальных запросов к DeepSeek
```

## Тесты

```powershell
python -m unittest discover -s tests -v
node --check web/app.js

```

## Ограничения

Используется веб-протокол DeepSeek, который может измениться. История в браузере восстанавливает контекст лишь приблизительно: очень длинные старые сообщения обрезаются.
